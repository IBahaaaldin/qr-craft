## 🌟 What is QR Craft?

**QR Craft Studio** is a client-side web application designed to turn raw text, academic references, study notes, checklists, and letters into organized, mobile-first reading pages accessible via QR code or direct link.

### Features
- 📚 **Academic Citation Parsing**: Automatically extracts author, year, title, publication source, and DOIs/hyperlinks into clean cards with one-click APA copying.
- 📝 **Structured Study Notes**: Highlights headings, key takeaways, and callout blocks.
- ✅ **Interactive Checklist**: Turns lines of text into clickable, strike-through to-do items.
- 💌 **Aesthetic Letter View**: Warm typography and date stamping for letters and personal notes.
- 🎨 **6 Hand-Crafted Color Themes**: Rose Petal, Lavender Dreams, Emerald Botanical, Warm Latte, Neon Indigo, and Minimalist Slate.
- 📱 **Real-Time Phone Simulator**: Live interactive preview inside an iPhone frame before generating.
- 🔒 **Zero Server & 100% Private**: State is compressed directly into the URL hash using LZ-String. No database, no tracking, never expires.
- 📲 **High-Res QR Export**: Instant PNG and SVG downloads with high error correction.
