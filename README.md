# Simple QR Generator

A fast, clean QR code generator that turns any file (.docx, .pdf, .xlsx, images, notes) or web link into an instant QR code.

## Features
- **Instant QR Code Generation**: Upload any file or paste a link to get a scannable QR code immediately.
- **Custom QR Colors**: Choose from modern preset palettes or pick any custom brand color.
- **Direct App Launch Option**: Includes an option to prompt opening files directly in their native application (such as Microsoft Word, Excel, PowerPoint, or PDF reader) or in the browser.
- **Vector & High-Res Export**: Download high-resolution PNG or copy the generated link.
